IPTK GitHub 바로가기 설치 방법
==============================
접속 주소: https://github.com/iptk38-del/iptk_1

[Windows] 자동 설치 (권장)
1. 이 압축파일을 마우스 오른쪽 클릭 → "압축 풀기" (꼭 압축을 푼 뒤 실행)
2. install_shortcut.bat 더블클릭
   - "Windows의 PC 보호" 창이 뜨면 → "추가 정보" → "실행"
3. 바탕화면에 IPTK 아이콘의 "IPTK GitHub" 바로가기가 생깁니다.

[Windows] 수동 설치
1. iptk_1.ico 를 C:\Users\Public\IPTK 폴더에 복사 (폴더가 없으면 만들기)
2. "IPTK GitHub.url" 을 바탕화면에 복사

[Mac]
1. "IPTK GitHub.webloc" 을 바탕화면 또는 Dock에 놓기
2. 아이콘 변경: iptk_icon.png 를 미리보기로 열고 ⌘A, ⌘C
   → .webloc 파일 선택 후 ⌘I → 왼쪽 위 작은 아이콘 클릭 → ⌘V

[휴대폰]
브라우저로 위 주소 접속 → 메뉴 → "홈 화면에 추가"
