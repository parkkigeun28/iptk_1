IPTK MES 바로가기 설치 방법
==============================
접속 주소: https://hcsmart.github.io/iptk_1/

[Windows] 설치
1. 압축파일을 마우스 오른쪽 클릭 → "압축 풀기"
2. IPTK_MES_Setup.exe 더블클릭
   - "Windows의 PC 보호" 창이 뜨면 → "추가 정보" → "실행"
   - 관리자 권한 필요 없음
3. 설치 완료 → 바탕화면과 시작 메뉴에 "IPTK MES" 아이콘이 생깁니다.

[Windows] 제거
설정 → 앱 → 설치된 앱 → "IPTK MES 바로가기" → 제거
(또는 시작 메뉴 → IPTK MES → IPTK MES 제거)

[Mac]
1. "IPTK MES.webloc" 을 바탕화면 또는 Dock에 놓기
2. 아이콘 변경: iptk_icon.png 를 미리보기로 열고 ⌘A, ⌘C
   → .webloc 파일 선택 후 ⌘I → 왼쪽 위 작은 아이콘 클릭 → ⌘V

[휴대폰]
브라우저로 위 주소 접속 → 메뉴 → "홈 화면에 추가"
